# Simple-Calculator

**Это калькултор он умеет выплнять 4 дествия: + - * //**

## Как использовать

- намите на файл main.py или simple-calc.exe в завиимости где скачали
- выберите действие или действия
- при завершении испольузете CTRL+C

**Данное ПО не умеет выполнять сложые примеры типа (12+12) - (5+5)= но вы можете по очере5ди с порядко дествия считать**
